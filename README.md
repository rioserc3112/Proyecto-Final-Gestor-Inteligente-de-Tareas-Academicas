# Proyecto-Final-Gestor-Inteligente-de-Tareas-Academicas
Aplicación de escritorio en Java con MySQL para gestionar tareas y subtareas académicas. Permite registrar, editar y eliminar tareas con responsables y login de usuario. Basada en arquitectura MVC, con módulo preparado para integrar IA (Hugging Face) y automatizar el registro inteligente de tareas.
